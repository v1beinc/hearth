# Hearth

A tiny, living pixel-art cabin for quiet evenings, inspired by the cozy atmosphere
of Terraria and Minecraft. Keep a fire on your second monitor, watch the snow,
and let the occasional visitor turn a simple background into a little world.

![A quiet evening in Hearth](assets/cabin.gif)

## Inside the cabin

- A flickering fireplace, warm light, soft shadows, frosted window glass and steaming coffee.
- A ginger cat that visits, curls up by the fire, breathes in her sleep and wanders away.
- Snow, blizzards, drifting clouds and changing moon phases.
- Rare creeper, skeleton and zombie visitors, shooting stars, and a Santa sleigh on clear full-moon nights.
- A mantel clock that follows real Moscow time, even when the animation is paused.
- Night, dawn, daytime and sunset lighting, or a gradual cycle following the Moscow clock.
- Soft fire and wind sounds, plus a native local-music player with volume and seeking.

The art is generated by a GLSL shader on a 320×180 grid. The scene adapts to the
window, framebuffer and aspect ratio, with crisp integer-sized pixel blocks and
no texture filtering. It fits the entire cabin on narrow displays and extends
the walls on ultrawide screens. Resize the window or switch to fullscreen;
no manual resolution setting is needed.

No external textures or game assets. Weather and moon phases follow a fictional
scene calendar; the cat's snoring is visual. Sound starts only when requested.

## Run

Requires Python 3.11+, [uv](https://docs.astral.sh/uv/), and an OpenGL 3.3-capable GPU.
Tested on Windows; dependencies are declared in the scripts and installed by uv.

```sh
git clone https://github.com/v1beinc/hearth.git
cd hearth
uv run hearth.py
```

Use `uv run hearth.py --windowed 1280x720` for a window. Fullscreen defaults to the
second monitor and falls back to the primary display if it is unavailable.

| Key | Action |
|---|---|
| `H` / `F1` | Help |
| `Space` | Pause animation |
| `1`–`4` | Evening / night / hot fire / retro |
| `W` | Change weather |
| `T` | Dawn / day / sunset / live Moscow daylight / night |
| `M` | Fireplace and wind on / off |
| `9` / `0` | Decrease / increase ambient sound volume |
| `Y` | Show / hide the native music player |
| `G` | Scene controls: animation speed, pixel size, flame size |
| `↑` / `↓` or `[` / `]` | Animation speed |
| `,` / `.` | Pixel size |
| `-` / `=` | Light intensity |
| `E` | Preview rare events more frequently |
| `F` | Toggle fullscreen |
| `S` | Save a screenshot |
| `R` | Restore startup settings |
| `Q` / `Esc` | Quit (`Esc` dismisses an open panel first) |

Edit `hearth.toml` to customize the scene.
[Detailed guide in Russian](docs/RUNNING.ru.md).

## Music and sound

`M` enables the bundled, original synthesized sounds. `9` / `0` adjust their
volume. They pause with the scene and when the application is minimized.
Fire and wind need no internet; wind becomes louder in the selected blizzard mode.
The loops are composed in [tools/generate_audio.py](tools/generate_audio.py),
without third-party recordings or samples.

`Y` opens a small player inside the native Hearth window: play/pause, seeking,
±30-second jumps, independent music volume, repeat and a native file picker.
MP3 audio streams through pyglet's local media backend; no browser or internet
is required. Music continues when the panel is dismissed, the scene is paused,
or Hearth is minimized. Exiting the app stops playback.

Select **Открыть трек** to load your own MP3 or WAV, or launch with
`uv run hearth.py --music "path/to/mix.mp3"`. A local `music/lofi-mix.mp3` is used
automatically when present; otherwise the player offers Hearth's original
48-second lofi composition. Imported recordings stay local and are ignored by Git.
Audio-format support depends on the platform's available decoders; MP3 and WAV
have been verified on Windows. The separate WebGL development preview retains
its optional visible YouTube player.

`G` shows separate sliders for speed, pixel size and flame size. Animation speed
changes preserve the current scene phase and do not alter the pixel grid or
flame-size setting. These controls fit small, portrait and large windows.

Night remains the default. Press `T` to explore other lighting, or set
`uDayMode = 0` in `hearth.toml` to follow Moscow time. The daylight cycle is an
artistic schedule, not astronomical sunrise data.

## Development

Python hosts the window; ModernGL renders the shader. The same scene also runs
in the local WebGL preview at `tools/preview.html`. Start it with
`python -m http.server 8765 --bind 127.0.0.1`, then open
`http://127.0.0.1:8765/tools/preview.html?shader=hearth`.

```sh
uv run --with pytest --with moderngl --with pyglet --with numpy --with pillow python -m pytest tests -q
```

The suite checks actual GPU pixels and the application event loop, including
window resizing and multiple display formats. The original terminal prototype
remains in `terminal_fireplace_cinematic.py`.
